# Muhammad Rizwan — AI & Pakistan Industries Portfolio

A Flask portfolio website with a separate searchable Pakistan Industries Explorer.

## Run on Windows / VS Code
```bat
py -m venv .venv
.venv\Scripts\activate.bat
py -m pip install -r requirements.txt
py app.py
```
Open: http://127.0.0.1:5000
